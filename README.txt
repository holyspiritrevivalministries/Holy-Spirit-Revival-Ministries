HOLY SPIRIT REVIVAL MINISTRIES — MOBILE PWA
================================================

Included:
- index.html: complete mobile-first ministry app
- manifest.webmanifest: installable app configuration
- sw.js: basic offline shell
- assets/ministry-logo.png: your supplied ministry logo, used as the app icon and branding

CONTENT COPIED FROM THE PROVIDED MINISTRY WEBSITE:
https://holyspiritrevivalmanyangwa-collab.github.io/Holy-Spirit-Revival-Ministries/

Weekly programs, ministry descriptions, leaders, address, phone numbers and email were taken from that page.

LEADER PHOTOS:
The supplied original photographs of Pastor Gloria Amule and Evangelist Keffa Darlington are now included in the app:
- assets/pastor-gloria.jpg
- assets/evangelist-keffa.jpg

The two supplied photographs are already installed in the assets folder.

YOUTUBE:
The YouTube button currently opens a YouTube search for the ministry because the website's underlying channel URL was not exposed by the page reader. Replace the URL in index.html with the ministry's exact YouTube channel URL when available.

HOW TO USE:
1. Keep the folder structure unchanged.
2. For a true installable PWA, host the folder on HTTPS (GitHub Pages works).
3. Open index.html/your hosted URL on a phone and use "Add to Home Screen".
4. The supplied orange logo is already configured as the app icon.

DESIGN:
Orange + white theme, bottom multi-navigation, side drawer navigation, responsive cards, scroll-reveal animations, contact actions, website link, YouTube link, weekly schedule and leader section.
